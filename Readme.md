# playlistApp
Exercício aula Java - 11 Novembro 2025 - Prof. Ramon

Atividade 1: Playlist Inteligente para Academia / Corrida
Construir um programa em Java que permita cadastrar músicas (nome + bpm + estilo).
O usuário deve poder adicionar, remover, listar e buscar músicas.
Regras obrigatórias:
 armazenar músicas em ArrayLists
 permitir filtrar por faixa de BPM (entre 120 e 160 por exemplo)
 permitir sugerir a ordem de execução usando laço for
